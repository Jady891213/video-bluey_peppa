## 官方开源路径

官方API保留内容审核，没有公开“关闭审核”或“非盈利自动豁免”的参数。[API错误码](https://platform.minimax.io/docs/api-reference/errorcode)只将1026/1027分别列为输入/输出内容敏感；[官方许可问答](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/QA-about-License.md)明确区分带审核的API与独立部署权重。

H3-Base可独立生成768p视频，官方列出的运行方式包括ComfyUI、SGLang和diffusers；Mac原生社区实现是h3.c。[官方仓库](https://github.com/MiniMax-AI/MiniMax-H3)、[官方整合入口](https://github.com/MiniMax-AI/awesome-minimax-h3-integration)。模型使用仍需遵守[Community License](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/LICENSE)，模型许可不包含第三方角色的权利，非盈利不能作为云端必然放行的依据。

本机已读到16GB物理内存、约12GiB剩余磁盘，未下载大权重。h3.c作者给出的参考音视频测试峰值约40.1GB；因此不能假定这台Mac能直接运行正式质量的H3。[作者实测](https://github.com/antirez/h3.c)。如走独立部署，应先落实另一个合适主机的硬件、模型许可适用地区和费用，再做4秒验证，不能先承诺质量与速度。

国内云GPU可评估AutoDL的按量实例。官方说明GPU按实例开关机时间计费，具体型号单价以实时主机列表为准；扩容数据盘关机后仍可能计费，停止GPU不等于释放所有存储费用。[官方计费规则](https://www.autodl.com/docs/price/)。本轮没有创建或购买云GPU。
